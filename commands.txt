Создание виртуальной среды:
python -m venv myvenv - windows
py -3.13 -m venv myvenv - если прошлая команда на Windows выдает просто Python, без создания виртуальной среды
python3 -m venv myvenv - Linux/MacOS

Активация виртуальной среды:
myvenv\Scripts\activate - windows
source myvenv/bin/activate - Linux/MacOS

Установка модулей питона в виртуальную среду:
pip install django psycopg2

django - фреймворк для написания back-end
psycopg2 - модуль для подключения базы данных PostgreSQL (Windows)
psycopg2-binary - модуль для подключения базы данных PostgreSQL (Linux/MacOS)

Просмотр модулей через терминал:
pip list

Экспорт списка пакетов с версиями:
pip freeze > requirements.txt

Установка пакетов из requirements.txt:
pip install -r requirements.txt

Создание ядра проекта:
django-admin startproject core .

Выгрузка миграций в БД:
python manage.py migrate

Создание приложения:
python manage.py startapp post

Сбор миграций (применять при изменении моделей):
python manage.py makemigrations

Запуск сервера:
python manage.py runserver

Остановка сервера:
ctrl+c - windows/Linux
command+c - MacOS
